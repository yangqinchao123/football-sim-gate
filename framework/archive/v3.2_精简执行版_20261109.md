# 足球预测硬框架 v3.2（精简执行版，2026-11-09）

> v3.2 不是再打补丁，而是按"硬闸门收敛、查实质不查形式、模型层校准、均势敢空仓"重构。
> 每条规则都有对应脚本、能机器校验；21 条历史错误模式降级为出票前背景知识库，不再当每批必走流程。
> 旧 v1.x–v3.1 原文留档溯源，冲突以本版为准。

## 通用纪律（单一出处，不重复）
事实优先不编造、三层分离、模型优先无硬证据不改序、锁定只追加、审计不做第二遍、逐场闭环禁批量、
批量防平独立举证——这些通用规则的权威定义在技能 **ai-research-discipline**（SKILL.md + discipline_rules.md），
本框架不再抄录，只讲足球场景怎么落地；通用规则与本框架冲突时，通用规则管原则、本框架管具体执行。

## 6 个硬闸门（前一闸不过，下一闸不启动；每个都查实质）

**G1 · 数据闸（M0，v2.1 教训：数据过期 54 天）**
- 脚本算 gap_days（最近比赛距比赛日真实天数），>21 天＝断档
- 断档场必须有近期手动模型 JSON（含真实 λ 数字，不是标题）；没有则该场不进票

**G2 · 取数情报闸（v2.0/v1.6 教训：混场次、伤停外推）**
- 官方四池真实 SP，按 businessDate 过滤，只留本业务日；文件只读
- **先探探球 AI，不许默默跳过（D38 教训）**：G2 第一步探测探球域名与登录态，能用就必须抓情报、落产物；不能用（宕机/登录失效）当场报"探球不可用"并留痕，再用公开多源替代，禁止无声跳过
- 情报核心 6 项：战意/排名、伤停+替代者三问、主客形态、交锋、赛程体能、裁判，须有实质内容
- 伤停答不出"谁顶替/踢法变不变/终结点在不在"，不许因伤停看弱
- **结构变化触发器（D39 教训）**：核心腿强制检查是否存在核心球员永久退役/转会、换帅、体系球员长期伤缺。命中即与"短期伤停"区分：历史模型按旧体系算出的概率标记不可信，新体系未跑出≥5 场样本前该场禁止当核心，须降级或空仓；对手头号射手近期状态为强制对位项，写不出具体反击路径不许当最硬核心

**G3 · 模型闸（penaltyblog，查实质）**
- 泊松/普通 DC/衰减 DC 输出 λ、H/D/A、让球概率、比分，落 JSON；三模型一致才是强信号
- 攻防强度主客场分离、向联赛均值收缩，禁硬编码（已修 1.10/0.90 主场优势 bug）
- **平局模型层校准**：套用 `draw_calib_map.json`（多赛季 isotonic 拟合，8873 样本验证 RPS 改善），把极端平局概率往基准收敛，再归一 H/A；不做全局硬回补
- 缺数据场标 null，概率和≈1、λ>0 才放行

**G4 · 碰撞 + 实质 + 流程审计闸（恢复独立子 agent，查实质）**
- 碰撞子 agent 隔离：禁读主结论/市场/GRC/审计目录，自建模型独立推方向，信息源与主分析分化
- **红队无条件对立（D39 教训，硬职责）**：碰撞子 agent 唯一立场是反对，无论主分析对错，都必须主动找漏洞、把攻击角度打满，禁止主动附和、禁止看到有道理就认输、禁止中立评估；它只能在被主分析用可验证硬证据逐条驳倒后才"被打服"，收敛只能发生在充分对抗之后
- **事实层对质，不在概率层选边（D39 教训）**：分歧必须拆成可验证的具体事实（主客战绩、反弹动力、伤停替代、对位、对手头号射手状态），用证据多轮交锋；禁止停在"模型概率不同"然后由主分析拍板
- **独立反向不可单方推翻（D39 教训）**：独立模型 argmax 与主分析相反时，无论差距多小，要么拿可证伪硬证据彻底驳倒，要么该场不进票；差距极小（如 0.002）属"模型未决"，按不进处理，禁止解释成支持自己
- `substance_gate.py` 机器校验：clash_rounds≥2、每轮含具体证据（数字/球员球队/非套话）、两轮不雷同、抽象套话密度<0.30、有独立模型产物、verdict 处置明确、红队无主动附和
- 对质完仍无法用硬证据消除分歧＝没看透（含多轮僵持的真均势），不进票，禁主观站队
- **流程审计（独立子 agent，碰撞后进行）**：碰撞对质完成后，由另一个流程审计子 agent 按 11 项清单只查这场的框架流程与纪律是否走到位（数据/情报/模型/碰撞/证据真伪/锁定纪律），输出合规/不合规；不推方向、不做第二遍分析。审计合规且碰撞 PASS，该场 GRC 才放行进入 G5

**G5 · 方向表 + owner 确认闸（v2.4 教训：未确认即配单）**
- 只输出 GRC PASS 的场，先给全方向表、不给配单
- owner 确认留痕（confirmed、approved_nums、时间戳），没确认不进配单

**G6 · 配单 + 临场 + 锁定闸（v2.4 教训：漏让球）**
- `no_bet_gate.py` 空仓判定：触发 N1–N5 任一即该场不进票（见下）
- HAD + HHAD 必须都覆盖；注码：单腿≤50%、高风险（赔率>3.5）≤30%、总注≤余额40%、同联赛不配对、禁共同命门
- **风险点不解决不下桌（D38 教训）**：GRC 标"软腿/平局风险/信心略低"只代表"这里还没看透"，必须继续挖到有明确结论，禁止停在"有风险"。挖透后二选一：硬证据说能赢→敢当核心；硬证据说会出事或关键信息查不到→明确放弃、老实空仓。**没有"小注博"这种和稀泥的中间态。**
- 博单定义：有把握、但市场给高赔，才小注博大钱，底气是分析不是侥幸；不被"凑三档/凑净盈利"的目标绑架硬凑
- 临场：live SP 另存（漂移>5% 回炉）、核首发、红队三问，出 LOCKED 单；单关仅 single=1 可买

**赛后闭环（不计出手闸）**：核赛果、结算、纪律事故/判断错误二分归因、回填台账、RPS/Brier 对均匀基准

## 空仓判定（N1–N5，触发任一即不进票；GRC 预测层仍每场必给方向）
- N1 数据断档且无可靠近期手动模型
- N2 模型最高概率 <0.40（无明显优势）
- N3 H/A 去水概率差 <0.10（均势）且无硬证据打破
- N4 纯泊松与 DC 首选方向不一致（模型分裂）
- N5 碰撞 final 判定"不进票"
- D36 事后验证：6 场空仓避开 4 个错误、仅漏 2 个正确，净收益为正

## 平局封闭清单（4 选 ≥2，机器校验；媒体预测不算）
1. 双方近期真实 λ 均 <1.1
2. 明确守平结构（死守/双方缺正印中锋且替代者三问通过/顶级门将/德比）；单纯伤停不算
3. 官方市场去水平局 ≥25%
4. 近 5 次交锋平局率 ≥40%（样本满 5）
- 软信号叠加（弱队主场高平局率+模型平局正 EV+对手客场连败）即使清单只中 1 条，也必须重评（错误模式 21）

## 研究深度（出手最低 L4，逆市场必须 L5）
- L4 能推演比赛剧本、进球路径、比分区间；L5 能说清市场为何错、可证伪、撤票信号
- 时间只作下限（每场≥10 分钟），用于换方向换信息源，不空等不磨时间；闸门查证据不查时长
- 逐场闭环、禁止批量的通用规则见 ai-research-discipline；足球口径：单场 GRC 放行才开下一场，不并行、不占坑回填

## 子 agent 职责边界（足球分工；通用审计/改序纪律见 ai-research-discipline）
| 子 agent | 足球场景唯一工作 |
|---|---|
| 流程审计子 agent | 按 11 项清单审计框架流程与纪律，输出合规/不合规 |
| 碰撞子 agent | 隔离自建模型、无条件站对立面、事实层多轮对质到被硬证据打服、反向压力测试 |
| 事实核查（F3，按需临时启用，非每日固定） | 拿 GRC 事实清单回原始源逐条核对，用完即止 |
- 三类互不混岗、不互相读结论；隔离要求（禁读主结论/市场/GRC）按 G4 执行

## 单场 GRC 必含字段（填实、能复现才 PASS，不写"以官方为准"）
1. 核心 6 项情报 2. 三模型 λ/HDA/让球/比分（含平局校准）3. 碰撞逐轮记录与空仓判定 4. 平局封闭清单命中 5. 结论：HAD、HHAD（按钮名+含义）、最可能比分、冷门风险、可证伪翻车剧本

## 实证验证（2026-11-09，严格样本外，非自测）
- **平局校准样本外**：仅用 2223–2526 共 8444 样本拟合映射，预测 2627 的 429 场（全程不碰测试数据），RPS 0.2298→0.2230（改善约 3%）、Brier 0.6544→0.6214（约 5%），证明可泛化、非过拟合
- **空仓阈值敏感性**：N2 阈值 0.35–0.50 避错率稳定 0.62–0.67；N3 阈值 0.08–0.20 避错率 0.64–0.75，阈值不脆弱
- **实质闸门正反测**：真实碰撞记录 PASS，三类假套话/雷同/空记录全部 BLOCK

## 事实防御（治"写得具体却事实错误"，三层，从硬到兜底）
- **F1 数字事实脚本直出（最硬）**：积分榜、近期形态、主客拆分、进失球、交锋、xG 由 `fact_sheet.py` 从原始 CSV 直出成事实卡片，GRC 引用卡片、不手写数字；MainAgent 只解读、不陈述，从根上写不错
- **F2 外部事实双源核查**：伤停/复出由 `injury_check.py` 强制官方源+独立源机器比对，两源一致才 confirmed，单源/冲突标待核实，禁止当确定事实、禁止据此看弱；带采集时间防过期，临场首发以官宣为准
- **F3 独立事实核查（按需临时启用，不固化每日流程）**：机器无法自动核对、需回外部源判断的事实，临时单独开一个事实核查子 agent 逐条回原始源核对，只对事实真伪负责，用完即止；不设为每日固定第三道，避免子 agent 膨胀、假独立

## 能力边界（诚实声明，不夸大）
- 实质闸门能挡住空话、套话、磨时间、假对质；事实层再由 fact_sheet/injury_check 卡住"具体但错误"。残余风险：无法回到权威源核对、又被多源以讹传讹的事实仍可能漏，靠赛后归因补库
- 单批次验证仍有局限，最终检验靠接下来连续多批实战的 RPS/命中率/空仓稳定性，不凭一批下结论
- 模型在均势/爆冷场的内生不确定性无法消除，纪律保证的是"不硬选、敢空仓"，不是"保证猜中"
