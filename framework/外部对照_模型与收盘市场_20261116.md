# 外部对照：模型 vs 收盘市场（2026-11-16）

> 目的：不是自证，是把我们的模型放到公开的标尺上量一次。
> 结论一句话：**纯 DC 模型打不过收盘市场；把市场当底座、模型当分歧信号，是唯一站得住的用法。**

## 一、查到的外部做法（用于选标尺，不抄参数）

| 来源 | 做法 | 对我们的意义 |
|---|---|---|
| 学术与公开评测（RPS/Brier/LogLoss 为严格 proper scoring） | 用 RPS 比概率质量，用"最高项命中率"比方向 | 我们的台账三栏正是这个结构 |
| dashee87 / daisyguti 等 DC 实现 | 时间衰减权重，近场权重大 | 可测，测了才知道有没有用 |
| 公开融合类预测（DC + 庄家概率喂分类器） | 模型与市场概率并列做特征 | 融合是常见做法，但要自己验证 |
| clubelo / soccerdata | Elo 评分作为实力先验，有 CSV API | 可作后备先验，但站点常年过载 |
| fatih.ai 的模型阶梯 | DC 0.1926 RPS；分层贝叶斯 0.1927；特征模型更低 | 公开系统的 RPS 大致都在 0.19 一带，和收盘市场同量级 |

## 二、实验（可复现：`python3 research/blend_eval.py`）

- 数据：football_data 七个联赛；训练集 = 上赛季全部 + 当季已赛，滚动步长 10 场
- 市场基准：B365 收盘三向赔率去水（B365CH/CD/CA）
- 变量：时间衰减 xi ∈ {0, 0.0035, 0.007}；融合权重 w（模型占比）∈ {100%, 70%, 60%, 50%, 40%, 30%}
- 选参季 2526（6777 场），验证季 2627（1607 场），**只选参不调参**

| 方案 | 2526 RPS | 2627 RPS | 2627 命中 |
|---|---|---|---|
| 市场收盘（基准） | 0.1945 | **0.1960** | 55.4% |
| 纯模型 xi=0 | 0.2030 | 0.2068 | 54.1% |
| 纯模型 xi=0.0035 | 0.2028 | 0.2083 | 52.4% |
| 纯模型 xi=0.007 | 0.2042 | 0.2105 | 51.8% |
| 融合 w=30%（xi=0） | 0.1954 | 0.1966 | 56.0% |
| 融合 w=50%（xi=0） | 0.1968 | 0.1983 | 55.0% |

## 三、读出来的三件事

1. **纯模型比市场差约 5% RPS**（0.2068 vs 0.1960）。差距不是校准能补的，是信息量本身少。
2. **时间衰减在我们这套数据上是负收益**（xi 越大越差），因为训练集已含整季与上赛季，衰减等于丢样本。不采用。
3. **融合 w=30% 把概率质量拉回市场水平**（0.1966，差 0.0006），命中率 56.0% 略高于市场 55.4%，但 1.6 个百分点在 1607 场上约 1 个标准误，**不构成显著优势**。

## 四、据此改的规则

- 新增 `tools/blend.py`：由 `pb_dc + market_fair` 生成 `<批次>_blend.json`，给出融合方向 `dir`、模型方向 `model_dir`、分歧标记。
- `S6` 增加一条：**owner 方向与融合基准不一致，等同改序，必须留 evidence / falsifiable / replacement**。缺一 BLOCK。
- 台账 `stats` 增加融合列，四栏并排（锁定方向 / 模型最高项 / 市场最高项 / 融合），RPS 模型与市场并列。
- D42 豁免（规则落地前批次），其 007 正是"模型与市场分歧、仍按模型走"结果 1:4 的实例，留作反例。

## 五、没采纳的（写清理由，避免下次重炒）

- 时间衰减：实测负收益。
- Elo 先验：需要外部评分源，clubelo 站点频繁过载、无稳定 SLA；且当前模型已有联赛内攻防强度，边际收益未验证。
- 机器学习融合（XGB/LightGBM）：样本 1607 场，特征不足，先按线性融合把基线做稳。

## 六、边界

- 本实验的"市场"是 B365 收盘，不等于竞彩官方 SP；竞彩含较高抽水，**用竞彩 SP 当基准会系统性高估自己**。方向决策仍以去水概率为准。
- 2627 只有一个赛季的验证样本；要达到"融合优于市场"的结论，至少还需要 2–3 个赛季或 1000+ 场的独立验证。
