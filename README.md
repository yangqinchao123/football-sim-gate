# football-sim-gate

竞彩足球模拟盘的硬闸门 CI 仓库。目标：把 G1–G6 流程从"靠自觉"变成"云端强制"，检查不过无法合并。

## 目录
- `framework/`：唯一硬框架 v3.2
- `gates/`：闸门脚本（状态机、实质、空仓、出票前检查）
- `lib/`：事实卡片、伤停核查、平局校准
- `calib/`：平局 isotonic 校准表
- `daily/`：每日产物（按业务日建子目录）
- `data/`：数据占位（大数据不入库，按需脚本拉取）

## 工作流
每天出票走 PR：分支提交产物 → CI 自动跑闸门和泄密检查 → 全绿才允许合并（合并=放行）。
分支保护需在仓库设置中开启 required status checks。

## 纪律
- 密码/密钥只走 GitHub Secrets，禁止入库。
- 前闸不过不进下闸；独立碰撞红队无条件对立；风险点不解决不下桌。
