# 克罗地亚 vs 捷克 — 欧国联A级第3组第6轮 深度概率分析

一、赛事语境与数据甄别

语境定性：欧国联A级小组赛收官轮。主队克罗地亚5战1胜0平4负积3分排第3，不败即可锁定小组第三、避免直接降级；客队捷克5战0胜0平5负积0分垫底，必须取胜才有理论上的第三名争夺可能。这是典型的"一方保平、一方必须攻"的战意不对称结构，且为小组末轮，需警惕已经出局方的投入度（情报第13条已将客队战意由5/5下调至2/5，说明情报源认为捷克"迫切但可信度打折"）。

数据甄别：情报中"佩里西奇红牌停赛"与伤停名单相互印证（同一事实只计一次）；捷克的"Ladislav Krejčí停赛"与情报第5条"卡拉贝茨、舒尔茨伤缺"属同一来源族，不重复计数。多维度评分显示"主队伤停3人、客队伤停4人"——但捷克伤停集中于后防（Krejčí停赛、Hranáč膝伤），这正是融合λ给主队×1.02的直接依据；而捷克同时回收绍切克（伤愈回归）与赫洛热克，这是模型未完全定价的增量信息。

---

二、三源证据逐一评估
■ 模型源（融合引擎，基座）
进球期望：主2.28 / 客1.46（基线2.27/1.45），修正仅±2%：主队×1.02（捷克后防减员）、客队×1.02（克罗地亚门将/后卫线减员）、双方×0.98（主裁戈迪尼奥执法场均2.59球，显著低于λ基线）。
注意一处结构性矛盾：报告标注主裁场均2.59球"较本场λ基线3.73低30%"，但实际只施加了×0.98。即裁判的低进球属性未被充分定价，这使融合总λ 3.73偏高的风险实质存在。
HAD分布：主55.2% / 平20.9% / 客24.0%。
让球（-1）分布：主34.5% / 平20.7% / 客44.8%。
CRS：2:1(9.1%)、1:1(8.4%)、3:1(6.9%)、2:2(6.7%)；TTG：3球20.9%、4球19.6%、2球17.2%；HAFU：胜胜32.4%、平胜17.1%、负负12.6%。
模型信心度自评MEDIUM（缺xG高阶数据）。
■ 市场源（参照线）
去水概率：主65.5% / 平20.3% / 客14.2%，赔率全天零变动（胜1.34、平4.32、负6.2原封不动），无异动、无资金突袭信号，也无走势形态可读。
让球（-1）赔率2.19/3.4/2.58 → 归一化约 主40.1% / 平25.8% / 客34.1%，与模型分布方向相反（模型看客44.8%，市场看主40.1%）。
比分隐含：2:1(10.9%)、2:0(10.5%)、1:0(8.9%)、1:1(8.1%)、3:1(7.9%)、3:0(6.8%)。
总进球隐含：3球23.8% > 2球20.4% > 4球17.7%。
■ 信息源（证据修正）
主队进攻端实质减配（重要度4-5）：佩里西奇停赛（4场1球2助攻，20%进球率，是主队仅有的三名有进球记录者之一）、克拉马里奇伤缺、舒塔洛大腿拉伤、亚基奇膝伤成疑、苏契奇发烧退出。剩余锋线为贝尔乔（2场1球，20%）、帕沙利奇（3场1球，20%），均属低出场样本。
客队攻防两端此消彼长：后防失Krejčí（停赛）、Hranáč（膝伤）——防线削弱；但中场核心绍切克伤愈回归、赫洛热克入列——串联能力回升，且战术明确"收缩防线打反击，绍切克贴身限制莫德里奇"。捷克小组赛5战仅进2球、场均0.4球，进攻端的量级仍是硬约束（卡拉贝茨2场1球50%效率但已伤缺）。
主队状态与主场数据严重不佳：近10场4胜0平6负、进18失19；本届欧国联主场0胜0平2负、进1失9；近4场欧国联四连败、场均失3.5球。但这些失球主要来自英格兰（0:7）、西班牙（1:4、1:2）两支顶级队，对捷克的参考价值须下调。
交锋：5次交手克罗地亚2胜3平0负不败（主胜率40%、平率60%），2026年9月首回合客场2:1取胜，2025年6月曾主场5:1大胜，但2025年10月客场0:0——同一对手既能5:1也能0:0，方差极大。
天气与疲劳：晴、3.8℃、风速0.64m/s、降水0%——影响可忽略；双方均"近14天1场、休息3天"，赛程完全对等，无疲劳差。
裁判：戈迪尼奥本季74场，场均黄牌4.7（执法严格、比赛碎片化）、犯规26.9、场均进球2.59——利于防守方、压低净比赛时间与连续进攻，对"大胜"是负向因子。
■ 独立模型参照（dc-blend-v1）

主60.0% / 平22.2% / 客17.7%，与市场同向（交叉验证通过）。关键差异：其λ为主1.76/客1.29，总3.05球，明显低于融合引擎的3.73。按Poisson(3.05)计算，4+球概率约36.3%，与本站170场实测"4+球合计36.6%"高度吻合；而融合λ 3.73对应的4+球概率为51%，系统性偏离实测。这是本场最重要的量化甄别结论：融合总λ存在高估，dc-blend的3.05更接近真实分布。

三、分歧分析与采信

HAD层面：模型主胜55.2% vs 市场65.5%，分歧10.4pp（<15pp，不触发禁high，但融合报告已明确"信心封顶为中档"）。分歧来源清晰——模型对客胜给24.0%，市场仅14.2%（偏离+9.4pct），这是Elo系模型对弱队胜率的系统性高估（Elo 1496的捷克被赋予26.1%基础胜率，而市场只给14.2%）。模型与市场在"主胜方向"上一致，仅强度不同，故HAD方向采信主胜无争议，但强度按报告的封顶要求取medium。

让球层面：模型看客队44.8%，市场看主队40.1%，方向相反。但按1球盘纪律：让球方（克罗地亚）打穿是历史最优位（主让1球选打穿21/37=56.8%），且融合分布的反向概率44.8%尚在45%阈值之内（未构成"明显反向信号"）；同时历史经验规则2的触发条件为"主胜概率<55%且让1球"，本场融合55.2%、市场65.5%均不低于55%，不触发。故按纪律默认打穿方向，但因双方概率接近（34.5% vs 44.8%），置信度压至low。

总进球层面：采信dc-blend的3.05而非融合的3.73。依据三条：①裁判实际场均2.59球，融合仅施加×0.98，修正严重不足；②独立模型λ与本站实测4+球率（36.6%）几乎重合；③历史经验规则明确记录"欧国联—总进球预测偏高"已出现9次，典型案例（罗马尼亚0:1瑞典，融合λ5.28 vs 独立λ3.04，最终仅1球）与本场结构同型。叠加主队佩里西奇/克拉马里奇缺阵、捷克"收缩防线打反击"的低节奏战术取向，总进球应下修至2-3球区间。

四、各玩法推导
HAD（胜平负）：主胜

模型55.2%、市场65.5%同向，信息源整体支持（交锋5战不败、首回合客场2:1取胜、捷克小组赛5战全败且场均进球0.4、后防减员两人）。反向证据（克罗地亚主场0胜0平2负、四连败、佩里西奇/克拉马里奇缺阵）主要来自对英格兰、西班牙的失分，对捷克的可迁移性弱。分歧10.4pp按报告要求封顶中档 → medium。

HHAD（让球-1）：主胜（打穿）

融合分布 主34.5% / 平20.7% / 客44.8%。选择方=让球方，核心是净胜球能否≥2。按1球盘纪律，反向概率44.8%<45%且无"明显反向信号"（既非深盘、也非客队实力占优），默认打穿方向；卡盘概率20.7%处于15%-25%区间但并非三者最高（选卡盘历史仅31.5%，为最差档位，不选）。市场让球归一化亦给主队40.1%高于客队34.1%，两家在"克罗地亚净胜≥2"上都不低于34%，而捷克小组赛5战失12球、场均失2.4，客场对强队均失3球。风险明确：克罗地亚"保平即可"的战意结构 + 佩里西奇停赛 + 裁判低进球执法，最可能的失败形态正是"恰好赢1球"（占20.7%） → low。

CRS（比分）：3:1 + 1:1
首选3:1：融合给6.9%（仅次于2:1、1:1），市场9.0（隐含7.9%）；净胜2球，与HHAD=主胜（让1球打穿）净胜球自洽；同时是唯一能同时满足"4+球覆盖"（总λ 3.73>2.8，且捷克后防缺Krejčí、Hranáč，主队对捷克历史有5:1记录）与HHAD自洽的选项。
次选1:1：融合8.4%（第二高）、市场8.75（8.1%）；融合平局概率20.9%≥20%且非三者最高，按平局价值转移纪律，CRS必须由至少1个平局比分承接，1:1为首选承接位（140场实际平局中1:1占40.0%）；在独立模型λ 1.76/1.29下，1:1更是最高概率比分（约10.8%）。
两比分覆盖4球与2球两个不同档位；不选市场热度第二的2:1（本站实测2:1仅10.5%命中、2:0为0/6，市场对"胜利比分"存在系统性高估）。
TTG（总进球）：3 + 2

融合总λ 3.73 → 名义锚点在[3,4]，但按前述甄别下修至dc-blend的3.05后：2球约22.0%、3球约22.4%、4球约17.1%，[2,3]合计约44.4%，显著优于[3,4]的39.5%；市场隐含同为3球23.8%+2球20.4%=44.2%>[3,4]的41.5%。[2,3]为相邻组合且是历史最佳组合（本站准确率63.2%、覆盖44.1%实际比赛），3球既是模型最高单项（20.9%）也是市场最高（23.8%）且是历史单一最高频档位（24.1%）。不启用高进球上移[4,5]：虽然总λ≥3.2且≥5球前瞻31.4%≥25%两条件名义满足，但"欧国联总进球偏高"9次的历史归因、裁判2.59球的低进球执法、主队双前锋缺阵共同指向高估，上移属负优化 → medium。

HAFU（半全场）：胜胜 + 平平
首选胜胜：融合32.4%、市场42%均为最高，主场获胜比赛中半场亦领先概率约60%；符合"HAD方向一致"原则。
次选平平：融合平局概率20.9%≥20%，按平局承接纪律，次选位必须为全场平组合，优先平平（实际平局中HAFU=平平占59.3%）；平平只可作承接位、不可作首选（579场实测首选平平仅6.8%命中，为全系统最差首选位），置于次选恰是其正确用法。同时满足"2个中至少1个半场为平局"结构要求，且两个全场结果不同。
放弃平胜（17.1%）：在平局承接纪律优先于赔率直觉的前提下，平胜与平平不能并存于两个名额中，且两队半场进球能力均不算强（主队近4场欧国联多在上半场即失守）。 → low。
